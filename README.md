# Go с нуля до собеседования 🐹

Мой личный путь изучения языка Go: теория, практические задачи, разбор кода и вопросы для самопроверки.

Цель — не просто изучить синтаксис, а научиться самостоятельно писать программы на Go, понимать свой код, работать с Git/GitHub и постепенно выйти на уровень, необходимый для собеседования Go-разработчика.

## Как проходит обучение

Каждая новая тема проходит несколько этапов:

1. 🧠 Изучаю необходимую теорию.
2. 🎯 Самостоятельно решаю практическую задачу.
3. 🔎 Разбираю решение и найденные ошибки.
4. 📝 Сохраняю важные моменты в конспекте.
5. 🐙 Фиксирую результат отдельным Git-коммитом.
6. ☁️ Отправляю изменения на GitHub.

Главный принцип — **сначала пытаюсь решить самостоятельно, а готовое решение использую только после разбора собственных ошибок.**

## Git и GitHub

Каждая завершённая практическая задача фиксируется отдельным коммитом.

Пример истории:

```text
feat: add sum accumulator
feat: add even odd counter
feat: add multiplication table
feat: add age category checker
feat: add age check
feat: handle user input and errors
feat: add sum of two numbers
```

Таким образом Git-история становится частью процесса обучения и показывает реальный путь развития проекта.

## Принцип обучения

Не стремлюсь просто получить рабочую программу.

Важно понимать:

* почему код работает;
* что происходит во время выполнения;
* почему возникает ошибка;
* как исправить ошибку самостоятельно;
* какие конструкции Go были использованы;
* как сделать решение понятнее и аккуратнее.

## Цель

**Go с нуля → уверенное владение основами → структуры данных → interfaces → ошибки → concurrency → HTTP/API → тестирование → реальные проекты → подготовка к собеседованию.** 🐹

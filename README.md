# Go с нуля до собеседования 🐹

Мой личный конспект по языку Go: теория, разобранный код и вопросы для самопроверки. Собираю по мере изучения — цель выйти на собеседование Go-разработчика подготовленным.

## Как этим пользоваться

- Читаю конспекты по порядку (00 → 20).
- В конце каждого конспекта — вопросы для самопроверки, отвечаю на них своими словами перед тем, как двигаться дальше.
- Отмечаю пройденные темы в чек-листе ниже и коммичу изменение — так виден прогресс в истории репозитория.

# Go с нуля до собеседования 🐹

Мой личный путь изучения языка Go: теория, практические задачи, разбор кода и вопросы для самопроверки.

Главная цель — не просто прочитать теорию, а научиться писать код самостоятельно и постепенно выйти на уровень, достаточный для прохождения собеседования Go-разработчика.

## Как проходит обучение

Каждая тема состоит из нескольких этапов:

1. 🧠 Изучаю теорию.
2. 🎯 Решаю практическую задачу самостоятельно.
3. 🔎 Разбираю решение и ошибки.
4. 📝 Сохраняю важные моменты в конспекте.
5. 🐙 Фиксирую результат отдельным Git-коммитом.

Каждая практическая задача хранится отдельно, поэтому историю обучения можно просматривать непосредственно через Git.

## Git-история

Каждая завершённая практическая задача фиксируется отдельным коммитом.

Пример:

```text
feat: add sum of two numbers
feat: handle user input and errors
feat: add age check
```

Поэтому история Git показывает реальный прогресс обучения:

```text
изучение
   ↓
задача
   ↓
решение
   ↓
commit
   ↓
GitHub
```

## Принцип обучения

Не копирую готовое решение сразу.

Сначала пытаюсь решить задачу самостоятельно.

Если застрял — получаю подсказку.

После решения разбираю:

* почему код работает;
* почему возникла ошибка;
* какие конструкции Go были использованы;
* как можно сделать код лучше.

После этого сохраняю важные знания в `notes/`.

**Go с нуля → уверенное написание программ → работа с backend → concurrency → тестирование → реальные проекты → подготовка к собеседованию.** 🐹

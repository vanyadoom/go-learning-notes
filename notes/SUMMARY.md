📚 Конспект: Основы Go (Golang)
1. Фундамент и Типы данных

    Структура программы: Точка входа — func main() в пакете package main.
    Переменные: var name type или короткое объявление name := value.
    Базовые типы: int, float64, bool, string.
    Нулевые значения: Если переменная объявлена, но не инициализирована, она получает «нулевое» значение (0 для чисел, "" для строк, false для bool, nil для указателей/интерфейсов).
    Арифметика: Стандартные операторы +, -, *, /, % (остаток от деления).

2. Ввод/Вывод и Указатели

    fmt.Println: Вывод с переходом на новую строку.
    fmt.Scan(&var): Считывает данные до первого пробела. Важно: требует передачи адреса переменной через &.
    Указатели (& и *):
        &x — получить адрес переменной x.
        *p — разыменование (получить значение по адресу).
        Позволяют изменять переменные внутри функций, передавая их по ссылке.

3. Управление потоком

    if / else if / else: Условия пишутся без скобок. Можно объявлять переменные прямо в условии: if err := do(); err != nil { ... }.
    switch: Может работать без аргумента (как цепочка if-else). Автоматически делает break после каждого кейса.
    for: Единственный цикл в Go.
        Классический: for i := 0; i < 10; i++ {}
        While-подобный: for condition {}
        Бесконечный: for {}
    break: Прерывает выполнение цикла или switch.
    Диапазоны: Оператор ... используется в слайсах и массивах.

4. Функции и Область видимости 🟡

    Область видимости: Переменная видна только внутри блока {}, где она объявлена.
    Параметры и аргументы 🟡:
        По умолчанию передаются по значению (копируются).
        Чтобы изменить оригинал, нужно передавать указатель.
    Несколько возвращаемых значений: Идиома Go — (result, error).
    Счётчики и накопители 🟡: Частая практика в циклах for для подсчета суммы или количества элементов.

5. Коллекции: Массивы, Слайсы, Maps

    Массивы: Фиксированный размер [5]int. Редко используются напрямую.
    Слайсы: Динамические массивы []int.
        len(s) — количество элементов.
        cap(s) — вместимость (сколько памяти выделено).
        append(s, val) — добавление элемента (может создать новый слайс, если не хватает места).
    Maps: Хеш-таблицы map[key]value.
        m[key] — получение значения.
        value, ok := m[key] — безопасное получение (проверка существования ключа).
        Nil map: Нельзя записывать в nil-map, нужно инициализировать через make.
        range по map возвращает ключ и значение в случайном порядке.

6. Структуры и Методы (ООП в Go)

    Struct: Набор полей. type User struct { Name string }.
    Создание: User{Name: "Alex"} или new(User).
    Методы: Функции, привязанные к типу.
        Value receiver (func (u User)): Работает с копией структуры. Не может менять оригинал.
        Pointer receiver (func (u *User)): Работает с оригиналом. Обязательно использовать, если метод меняет состояние структуры 🟡.
    Проверка данных 🟡: Перед изменением состояния в методе всегда проверяйте входные данные и возвращайте error, если они некорректны.

7. Error Handling (Обработка ошибок) 🟡

    Тип error: Это интерфейс. Ошибка — это просто значение.
    Идиома: if err != nil { ... }. Ошибка всегда идет последним возвращаемым значением.
    Создание: errors.New("text") или fmt.Errorf("text: %w", err).
    %w (Wrap): Оборачивает ошибку, сохраняя цепочку причин.
    errors.Is(err, target): Проверяет наличие конкретной ошибки в цепочке.
    errors.As(err, &target): Пытается привести ошибку к конкретному типу.
    panic: Только для фатальных, непредвиденных сбоев. Не использовать для ожидаемых ошибок.
    nil ошибка: Вызов методов у nil-ошибки вызывает панику.

8. Строки, Байты и Руны (Strings) 🟡

    Неизменяемость: Строку нельзя изменить по индексу (s[0] = 'a' — ошибка компиляции).
    Кодировка: Go использует UTF-8.
    Байты vs Руны:
        len(s) — длина в байтах.
        []rune(s) — преобразование в слайс Unicode-символов.
        Кириллица = 2 байта, Эмодзи = 4 байта, Латиница = 1 байт.
    Индексация: s[i] возвращает байт (тип byte/uint8), а не символ.
    Пакет strings: Contains, Split, Join, Replace.
    Пакет strconv: Конвертация типов (Atoi, Itoa, ParseFloat).
    Слайсинг: s[start:end] работает с байтами.

# Программа курса: Go с нуля до собеседования

Полная теоретическая база языка Go, разбитая на конспекты. Каждый конспект — отдельный документ с теорией и рабочими примерами кода. Печатай и изучай по порядку.

## Блок 1. Основы языка
1. Введение в Go, установка, структура проекта, go.mod
2. Переменные, типы данных, константы, приведение типов
3. Управляющие конструкции: if/else, switch, единственный цикл for
4. Функции: множественный возврат, variadic, замыкания, defer

## Блок 2. Данные и структуры
5. Указатели (pointers)
6. Массивы и слайсы (slices) — устройство изнутри
7. Мапы (maps)
8. Структуры (structs) и методы
9. Интерфейсы, duck typing, type assertion/switch

## Блок 3. Надёжность кода
10. Обработка ошибок, panic/recover, кастомные ошибки, errors.Is/As
11. Пакеты, модули, видимость имён, go.sum

## Блок 4. Конкурентность (визитная карточка Go)
12. Горутины и каналы
13. select, sync.Mutex, sync.WaitGroup, sync.Once
14. Паттерны конкурентности и типичные ошибки (race conditions, deadlocks)

## Блок 5. Современный Go
15. Дженерики (generics, Go 1.18+)
16. Стандартная библиотека: strings, strconv, time, os, io, bufio
17. JSON и работа с net/http (базовый уровень)

## Блок 6. Инженерная культура
18. Тестирование: testing, table-driven tests, бенчмарки
19. Идиомы Go, gofmt, golangci-lint, code review checklist
20. Частые вопросы на собеседованиях + практические задачи

---

Двигаемся строго по порядку. После каждого конспекта — файл в /mnt/user-data/outputs, готовый к печати. Если какая-то тема нужна раньше остальных — просто скажи, поменяем порядок.

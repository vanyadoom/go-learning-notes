# Конспект 6. Массивы и слайсы

Это одна из самых важных тем для собеседований по Go — почти всегда спрашивают про `append` и capacity.

## 1. Массивы (arrays) — фиксированный размер

```go
var arr [5]int              // массив из 5 int, все нули
arr2 := [3]string{"a", "b", "c"}
arr3 := [...]int{1, 2, 3, 4} // размер выводится из количества элементов — [4]int

fmt.Println(len(arr3)) // 4
```

**Ключевое отличие от других языков:** размер массива — часть его **типа**. `[3]int` и `[5]int` — это два разных, несовместимых типа. Массивы копируются целиком при присваивании и передаче в функцию:

```go
a := [3]int{1, 2, 3}
b := a       // ПОЛНАЯ копия
b[0] = 100
fmt.Println(a[0]) // 1 — оригинал не изменился
```

На практике массивы используются редко — почти всегда используют слайсы.

## 2. Слайсы (slices) — динамический "вид" на массив

Слайс — это не массив, а маленькая структура из трёх полей:

```go
// Внутреннее устройство слайса (концептуально, не буквальный код):
type sliceHeader struct {
    ptr *T   // указатель на первый элемент базового массива
    len int  // текущая длина
    cap int  // ёмкость — сколько элементов помещается до необходимости пересоздания массива
}
```

Именно поэтому слайс — reference type: копирование слайса копирует эти три поля, а не сами данные, поэтому два слайса могут "смотреть" на один и тот же базовый массив.

```go
s := []int{1, 2, 3}        // литерал слайса
s2 := make([]int, 5)        // make([]T, len) — слайс длиной 5, заполнен нулями
s3 := make([]int, 3, 10)    // make([]T, len, cap) — длина 3, но ёмкость 10

fmt.Println(len(s3), cap(s3)) // 3 10
```

## 3. append и почему это самая частая тема на собеседовании

```go
s := make([]int, 0, 3) // len=0, cap=3
s = append(s, 1)       // len=1, cap=3 — есть место, новый массив НЕ создаётся
s = append(s, 2)       // len=2, cap=3
s = append(s, 3)       // len=3, cap=3 — заполнили всю ёмкость
s = append(s, 4)       // len=4, cap=6 (обычно capacity удваивается) —
                        // ЗДЕСЬ Go выделяет НОВЫЙ базовый массив и копирует данные!
```

**Критически важное следствие:** пока `cap` не превышен, `append` дописывает данные в тот же базовый массив. Как только `cap` превышен — создаётся новый массив, и старый слайс (если на него ещё кто-то ссылается) остаётся "смотреть" на старые данные.

```go
func addOne(s []int) {
    s = append(s, 99) // если cap хватало — изменения останутся ТОЛЬКО в этой копии заголовка слайса,
                       // вызывающий код их не увидит, если не вернуть s обратно!
}

original := make([]int, 2, 2)
addOne(original)
fmt.Println(original) // [0 0] — "99" никуда не попал!
```

**Правильный способ** — либо возвращать слайс из функции и переприсваивать, либо передавать указатель на слайс:

```go
func addOneCorrect(s []int) []int {
    return append(s, 99)
}
original = addOneCorrect(original)
```

## 4. Общий базовый массив — ловушка с "расшариванием" памяти

```go
a := []int{1, 2, 3, 4, 5}
b := a[1:3] // b = [2, 3], смотрит на ТОТ ЖЕ массив, что и a

b[0] = 999
fmt.Println(a) // [1 999 3 4 5] — изменение в b затронуло a!
```

`a[low:high]` — операция среза (slicing): создаёт новый слайс, но данные не копирует, а ссылается на тот же базовый массив, начиная с индекса `low` до `high` (не включая `high`).

**Если нужна независимая копия** — используй встроенную функцию `copy`:

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
n := copy(dst, src) // n — количество скопированных элементов
dst[0] = 999
fmt.Println(src) // [1 2 3] — не изменился, dst независим
```

## 5. Полезные операции со слайсами

```go
s := []int{1, 2, 3, 4, 5}

// удаление элемента по индексу i (сохраняя порядок)
i := 2
s = append(s[:i], s[i+1:]...)

// удаление элемента без сохранения порядка (быстрее)
s[i] = s[len(s)-1]
s = s[:len(s)-1]

// вставка элемента в позицию i
s = append(s[:i], append([]int{100}, s[i:]...)...)

// разворот слайса
for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
    s[i], s[j] = s[j], s[i]
}

// проверка на nil vs пустой слайс — ОБА безопасны для len() и range!
var nilSlice []int          // nil, len == 0
emptySlice := []int{}       // не nil, len == 0
fmt.Println(nilSlice == nil, emptySlice == nil) // true false
```

## 6. Слайс слайсов (двумерные структуры)

```go
grid := make([][]int, 3) // 3 строки
for i := range grid {
    grid[i] = make([]int, 4) // в каждой строке — 4 столбца
}
grid[1][2] = 99
```

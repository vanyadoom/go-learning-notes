# Конспект 2. Переменные, типы данных, константы

## 1. Объявление переменных

Go — язык со статической типизацией: тип переменной известен на этапе компиляции и не меняется.

```go
var x int          // объявление с явным типом, значение по умолчанию — 0
var y int = 10     // объявление с явным типом и значением
var z = 10         // тип выводится автоматически (int) — type inference
k := 10             // короткое объявление, ТОЛЬКО внутри функций
```

**Разбор:**
- `var` можно использовать и внутри, и вне функций (на уровне пакета).
- `:=` — оператор короткого объявления, работает только внутри тела функции. На уровне пакета так писать нельзя.
- Если переменная объявлена, но не используется — код **не скомпилируется**. Это осознанное решение авторов языка против «мусорного» кода.

```go
var (
    name string = "Alex"
    age  int    = 25
    isAdmin bool
)
```

Групповое объявление через скобки — идиоматичный способ объявить несколько переменных подряд.

## 2. Нулевые значения (zero values)

В Go у каждого типа есть значение по умолчанию — переменных без инициализации не бывает (в отличие от C, где переменная может содержать «мусор» из памяти):

| Тип | Нулевое значение |
|---|---|
| int, float64 | 0 |
| string | "" (пустая строка) |
| bool | false |
| pointer, slice, map, channel, func, interface | nil |

## 3. Базовые типы данных

```go
// Целые числа
var a int8   // -128..127
var b int16
var c int32
var d int64
var e int    // размер зависит от платформы: 32 или 64 бита (обычно 64)

// Беззнаковые
var f uint8  // 0..255, синоним — byte
var g uint32
var h uint64

// Числа с плавающей точкой
var i float32
var j float64 // используется по умолчанию, если не указано иное

// Прочие
var k byte    // алиас для uint8, используется для сырых байтов
var l rune    // алиас для int32, используется для символов Unicode
var m string
var n bool
```

> **Вопрос на собеседовании:** «Почему `rune` — это `int32`, а не `char`?» — В Go нет типа `char`. Строки в Go — это последовательности байт в кодировке UTF-8, а один символ Unicode (например, кириллическая буква или эмодзи) может занимать от 1 до 4 байт. `rune` хранит **один символ Unicode целиком**, поэтому это int32 (4 байта хватает под любой символ).

```go
s := "привет"
fmt.Println(len(s))          // 12 — это байты, а не буквы! Кириллица — 2 байта на символ
for i, r := range s {
    fmt.Printf("%d: %c\n", i, r) // range по строке итерируется по РУНАМ, не по байтам
}
```

## 4. Константы

```go
const Pi = 3.14159
const (
    StatusOK       = 200
    StatusNotFound = 404
)
```

Константы вычисляются на этапе компиляции, не могут быть результатом выполнения функции (кроме нескольких встроенных, например `len` для массивов фиксированного размера).

### iota — генератор последовательных констант

```go
type Weekday int

const (
    Monday Weekday = iota // 0
    Tuesday               // 1
    Wednesday             // 2
    Thursday              // 3
    Friday                // 4
    Saturday              // 5
    Sunday                // 6
)
```

`iota` сбрасывается в 0 в начале каждого блока `const` и увеличивается на 1 с каждой новой строкой. Классический идиоматичный способ создать «перечисление» (enum), которого как отдельной конструкции в Go нет.

Более сложный пример — битовые флаги:

```go
const (
    ReadPermission  = 1 << iota // 1 << 0 = 1
    WritePermission              // 1 << 1 = 2
    ExecPermission               // 1 << 2 = 4
)
```

## 5. Приведение типов (только явное!)

В Go **нет** неявного приведения типов даже между `int` и `int64` — это частый источник ошибок компиляции у новичков, но и защита от неявных багов.

```go
var i int = 42
var f float64 = float64(i)   // явное приведение обязательно
var u uint = uint(f)

var a int32 = 10
var b int64 = 20
// c := a + b                // ОШИБКА КОМПИЛЯЦИИ: mismatched types
c := int64(a) + b            // так — правильно
```

Приведение строки в число (и обратно) идёт не через `int()`, а через пакет `strconv`:

```go
import "strconv"

n, err := strconv.Atoi("123")       // string -> int
s := strconv.Itoa(123)              // int -> string
f, err := strconv.ParseFloat("3.14", 64)
b, err := strconv.ParseBool("true")
```

Обрати внимание: везде, кроме `Itoa`, функция возвращает **два значения** — результат и ошибку. Это база философии обработки ошибок в Go (разберём подробно в конспекте 10), но уже сейчас важно взять за привычку всегда проверять `err`:

```go
n, err := strconv.Atoi("abc")
if err != nil {
    fmt.Println("не удалось преобразовать:", err)
}
```

## 6. fmt.Printf verbs (форматирование вывода)

Пригодится буквально везде, поэтому лучше выучить сразу:

```go
fmt.Printf("%d\n", 42)        // целое число
fmt.Printf("%f\n", 3.14)      // float, 6 знаков после запятой по умолчанию
fmt.Printf("%.2f\n", 3.14159) // float с 2 знаками после запятой
fmt.Printf("%s\n", "hello")   // строка
fmt.Printf("%t\n", true)      // bool
fmt.Printf("%v\n", anyValue)  // "универсальный" формат — значение по умолчанию для любого типа
fmt.Printf("%+v\n", struct{}) // как %v, но со именами полей структуры
fmt.Printf("%T\n", anyValue)  // выводит ТИП значения — незаменимо при отладке
fmt.Printf("%p\n", &x)        // адрес в памяти (указатель)
```

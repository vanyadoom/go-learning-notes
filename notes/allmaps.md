# Go — Map

## 1. Что такое `map`

`map` — структура данных, которая хранит пары:

```text
ключ → значение
```

Например:

```go
ages := map[string]int{
    "Ivan": 25,
    "Alex": 30,
    "John": 22,
}
```

Здесь:

```text
string → тип ключа
int    → тип значения
```

Получается:

```text
"Ivan" → 25
"Alex" → 30
"John" → 22
```

В отличие от `slice`, где элементы обычно получают по индексу, в `map` значение получают по ключу.

---

# 2. Создание `map`

Можно сразу создать и заполнить `map`:

```go
ages := map[string]int{
    "Ivan": 25,
    "Alex": 30,
}
```

Можно создать пустой `map` с помощью `make`:

```go
ages := make(map[string]int)
```

После этого в него можно добавлять элементы:

```go
ages["Ivan"] = 25
ages["Alex"] = 30
```

---

# 3. Добавление элемента

Для добавления используется:

```go
map[key] = value
```

Например:

```go
ages["Ivan"] = 25
```

Если такого ключа раньше не было, элемент добавляется.

---

# 4. Изменение элемента

Та же конструкция используется для изменения существующего значения:

```go
ages["Ivan"] = 26
```

Если ключ `"Ivan"` уже существует, старое значение будет заменено.

То есть:

```go
ages["Ivan"] = 25
ages["Ivan"] = 26
```

после этого:

```text
"Ivan" → 26
```

---

# 5. Получение значения

Чтобы получить значение по ключу:

```go
age := ages["Ivan"]
```

или сразу вывести:

```go
fmt.Println(ages["Ivan"])
```

Если `"Ivan"` существует и его значение равно `25`, будет получено:

```text
25
```

---

# 6. Что происходит, если ключа нет

Если запрашиваем несуществующий ключ:

```go
fmt.Println(ages["Unknown"])
```

Go вернёт **нулевое значение типа значения**.

Для `int`:

```text
0
```

Для `string`:

```text
""
```

Для `bool`:

```text
false
```

Поэтому простого:

```go
value := ages["Unknown"]
```

недостаточно, если нужно отличить:

```text
ключ отсутствует
```

от:

```text
ключ существует, но значение равно zero value
```

---

# 7. Проверка существования ключа

Для этого используется специальная форма:

```go
value, ok := ages["Ivan"]
```

Здесь:

```text
value → значение
ok    → существует ли такой ключ
```

Если ключ существует:

```text
value = 25
ok = true
```

Если ключа нет:

```text
value = 0
ok = false
```

---

# 8. `ok`

`ok` — это логическая переменная типа `bool`.

Например:

```go
age, ok := ages["Ivan"]

if ok {
    fmt.Println("Возраст:", age)
} else {
    fmt.Println("Студент не найден")
}
```

Если `"Ivan"` есть в `map`, будет выполнена первая ветка.

Если ключ отсутствует — вторая.

Общая схема:

```go
value, ok := map[key]

if ok {
    // ключ существует
} else {
    // ключ отсутствует
}
```

---

# 9. Если значение не нужно

Иногда нужно только проверить наличие ключа.

Тогда значение можно проигнорировать через `_`:

```go
_, ok := ages["Ivan"]

if ok {
    fmt.Println("Студент найден")
}
```

Здесь:

```text
_  → значение игнорируется
ok → сохраняется результат проверки
```

---

# 10. Удаление элемента

Для удаления используется:

```go
delete(map, key)
```

Например:

```go
delete(ages, "Ivan")
```

После этого ключ `"Ivan"` больше не существует.

Если удалить несуществующий ключ:

```go
delete(ages, "Unknown")
```

ничего страшного не произойдёт.

---

# 11. Количество элементов

Для получения количества элементов используется:

```go
len(ages)
```

Например:

```go
ages := map[string]int{
    "Ivan": 25,
    "Alex": 30,
}
```

Тогда:

```go
len(ages)
```

даст:

```text
2
```

Для `map` `len` означает количество пар:

```text
ключ → значение
```

---

# 12. Перебор `map`

Для перебора используется `range`:

```go
for name, age := range ages {
    fmt.Println(name, age)
}
```

Например:

```text
Ivan 25
Alex 30
John 22
```

Но важно:

> **Порядок обхода `map` не гарантирован.**

Нельзя строить логику программы на том, что элементы будут возвращаться в определённом порядке.

---

# 13. Получить только ключи

Если значение не нужно:

```go
for name := range ages {
    fmt.Println(name)
}
```

Здесь используется только ключ.

---

# 14. Получить только значения

Если ключ не нужен:

```go
for _, age := range ages {
    fmt.Println(age)
}
```

`_` здесь игнорирует ключ.

---

# 15. Типы ключей

При объявлении `map` указывается тип ключа и тип значения:

```go
map[string]int
```

означает:

```text
ключ     → string
значение → int
```

Например:

```go
users := map[int]string{
    1: "Ivan",
    2: "Alex",
}
```

Здесь:

```text
ключ     → int
значение → string
```

---

# 16. Ключ и значение — это разные вещи

Например:

```go
users := map[int]string{
    1: "Ivan",
    2: "Alex",
}
```

Здесь:

```text
1 → ключ
"Ivan" → значение
```

Поэтому:

```go
users[1]
```

вернёт:

```text
"Ivan"
```

---

# 17. Тип ключа должен подходить

Если `map` имеет тип:

```go
ages := map[string]int{
    "Ivan": 25,
}
```

ключ должен быть `string`.

Так можно:

```go
ages["Ivan"]
```

А так нельзя:

```go
ages[10]
```

потому что `10` имеет тип `int`, а `map` ожидает `string`.

---

# 18. `nil map`

Можно объявить `map` без создания:

```go
var ages map[string]int
```

В этом случае:

```text
ages == nil
```

Такой `map` можно читать:

```go
fmt.Println(ages["Ivan"])
```

Это безопасно и вернёт zero value:

```text
0
```

Но записывать в него нельзя:

```go
ages["Ivan"] = 25
```

Такая запись приведёт к **ошибке времени выполнения**.

---

# 19. Как создать `map`, в который можно записывать

Используем:

```go
ages := make(map[string]int)
```

Теперь запись работает:

```go
ages["Ivan"] = 25
```

Также можно создать `map` сразу с данными:

```go
ages := map[string]int{
    "Ivan": 25,
}
```

---

# 20. Разница между `nil map` и пустым `map`

### `nil map`

```go
var ages map[string]int
```

```text
ages == nil
```

Запись запрещена.

### Пустой созданный `map`

```go
ages := make(map[string]int)
```

```text
ages != nil
```

Запись разрешена.

Оба могут иметь:

```go
len(ages) == 0
```

Но это разные состояния.

---

# 21. `map` передаётся как значение

В Go `map` не является буквально "передачей по ссылке".

`map` передаётся как значение, но это значение предоставляет доступ к внутренней структуре `map`.

Поэтому копии переменной `map` могут работать с одними и теми же данными.

Например:

```go
a := map[string]int{
    "Ivan": 25,
}

b := a

b["Ivan"] = 30
```

После этого:

```text
a["Ivan"] → 30
b["Ivan"] → 30
```

Поэтому присваивание `b := a` не создаёт независимую копию всех элементов `map`.

---

# 22. `map` и `slice`

## Slice

Доступ обычно идёт по индексу:

```go
numbers[0]
numbers[1]
numbers[2]
```

Например:

```text
0 → 10
1 → 20
2 → 30
```

## Map

Доступ идёт по ключу:

```go
ages["Ivan"]
ages["Alex"]
```

Например:

```text
"Ivan" → 25
"Alex" → 30
```

Главная разница:

```text
slice → индекс
map   → ключ
```

---

# 23. `map` и `array`

### Array

Имеет фиксированный размер:

```go
numbers := [3]int{10, 20, 30}
```

Доступ:

```go
numbers[0]
```

### Map

Хранит пары ключ-значение:

```go
ages := map[string]int{
    "Ivan": 25,
}
```

Доступ:

```go
ages["Ivan"]
```

# 25. Самая важная схема

Для `map` нужно уверенно понимать эти конструкции:

```go
m[key] = value
```

добавить или изменить значение.

```go
value := m[key]
```

получить значение.

```go
value, ok := m[key]
```

получить значение и проверить существование ключа.

```go
delete(m, key)
```

удалить элемент.

```go
len(m)
```

получить количество элементов.

```go
for key, value := range m {
    ...
}
```

перебрать `map`.

# 27. Мини-шпаргалка

```go
// создание
users := make(map[string]int)

// добавление
users["Ivan"] = 25

// изменение
users["Ivan"] = 26

// получение
age := users["Ivan"]

// проверка
age, ok := users["Ivan"]

if ok {
    fmt.Println(age)
}

// удаление
delete(users, "Ivan")

// количество
fmt.Println(len(users))

// перебор
for name, age := range users {
    fmt.Println(name, age)
}
```

Главная мысль:

```text
MAP = ключ → значение
```

И самый важный паттерн:

```go
value, ok := m[key]

if ok {
    // ключ существует
} else {
    // ключ отсутствует
}
```

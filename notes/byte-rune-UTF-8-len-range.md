## 7. Шпаргалка: byte, rune, UTF-8, len и range

Главное правило:

```text
byte ≠ rune
байт ≠ символ
индекс ≠ номер символа
len(string) ≠ количество символов
```

### Пример

```go
text := "AЯB"
```

Человек видит 3 символа:

```text
A   Я   B
```

Но в UTF-8 они занимают:

```text
A → 1 байт
Я → 2 байта
B → 1 байт
```

Поэтому строка занимает всего 4 байта.

### len(string)

```go
len(text)
```

возвращает количество **байтов**.

Для:

```go
text := "AЯB"
```

результат:

```text
4
```

### Количество символов

Чтобы посчитать Unicode-символы:

```go
len([]rune(text))
```

Для `"AЯB"`:

```text
3
```

### rune

`rune` — один Unicode-символ.

Например:

```text
'A'
'Я'
'Б'
```

В цикле:

```go
for _, r := range text {
}
```

`r` — текущий символ.

Для `"AЯB"`:

```text
1 проход → r = 'A'
2 проход → r = 'Я'
3 проход → r = 'B'
```

### i в range

В:

```go
for i, r := range text {
}
```

`i` — не номер символа.

`i` — **байтовый индекс начала текущего символа**.

Для:

```go
text := "AЯB"
```

получаем:

```text
i = 0   r = 'A'
i = 1   r = 'Я'
i = 3   r = 'B'
```

Почему у `B` индекс `3`:

```text
A       Я         B
[0]   [1][2]     [3]
```

`Я` занимает два байта: `1` и `2`.

### text[i]

```go
text[i]
```

возвращает **один byte**, а не целый Unicode-символ.

Поэтому:

```go
text := "Я"
fmt.Println(text[0])
```

не выводит букву `Я`.

Это только первый байт её UTF-8 представления.

### range по string

Для посимвольной работы с Unicode обычно удобнее:

```go
for i, r := range text {
}
```

Запомнить:

```text
i → байтовый индекс
r → текущий rune
```

### string(r)

Если `r` — rune:

```go
string(r)
```

преобразует его в строку.

Например:

```go
r := 'Я'
fmt.Println(string(r))
```

выведет:

```text
Я
```

### Самая короткая памятка

```text
len(text)        → байты
len([]rune(text)) → символы

text[i]          → byte

i в range        → байтовый индекс
r в range        → текущий символ

string(r)        → rune превращаем в string
```

# Конспект 4. Функции

## 1. Базовый синтаксис

```go
func add(a int, b int) int {
    return a + b
}

// Если типы соседних параметров совпадают — можно указать один раз
func multiply(a, b int) int {
    return a * b
}
```

## 2. Множественный возврат значений

Одна из ключевых особенностей Go, которой нет в большинстве мейнстримных языков — функция может возвращать сразу несколько значений. Это и есть основа стандартной обработки ошибок в Go.

```go
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("деление на ноль")
    }
    return a / b, nil
}

result, err := divide(10, 2)
if err != nil {
    fmt.Println("ошибка:", err)
    return
}
fmt.Println(result)
```

### Именованные возвращаемые значения (named return values)

```go
func divide(a, b float64) (result float64, err error) {
    if b == 0 {
        err = errors.New("деление на ноль")
        return // "голый" return — вернёт текущие значения result и err
    }
    result = a / b
    return
}
```

Именованные значения автоматически объявляются как переменные с нулевыми значениями в начале функции. Это удобно для читаемости сигнатуры, но злоупотреблять "голыми" `return` в длинных функциях не стоит — снижает читаемость.

## 3. Variadic-функции (переменное число аргументов)

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

sum(1, 2, 3)        // 6
sum()                // 0, nums == nil

// "Разворачивание" слайса в variadic-аргументы через ...
numbers := []int{1, 2, 3, 4}
sum(numbers...)
```

Внутри функции `nums` — это обычный слайс `[]int`. Variadic-параметр обязан быть последним в списке параметров.

Классический пример из стандартной библиотеки: `fmt.Println(a ...interface{})` — именно поэтому в неё можно передать сколько угодно аргументов любых типов.

## 4. Функции как значения первого класса (first-class functions)

Функции в Go можно присваивать переменным, передавать как аргументы, возвращать из других функций — они полноценные значения, как числа или строки.

```go
// Тип "функция"
var operation func(int, int) int

operation = func(a, b int) int {
    return a + b
}
fmt.Println(operation(2, 3)) // 5

// Функция как параметр
func apply(a, b int, op func(int, int) int) int {
    return op(a, b)
}
fmt.Println(apply(4, 5, func(a, b int) int { return a * b })) // 20

// Функция как возвращаемое значение
func multiplier(factor int) func(int) int {
    return func(x int) int {
        return x * factor
    }
}
double := multiplier(2)
fmt.Println(double(10)) // 20
```

## 5. Замыкания (closures)

Функция, возвращённая из `multiplier` выше — это замыкание: она "запоминает" (захватывает) переменную `factor` из внешней области видимости, даже после того, как `multiplier` завершила выполнение.

**Классический пример — счётчик:**

```go
func counter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

c1 := counter()
fmt.Println(c1()) // 1
fmt.Println(c1()) // 2
fmt.Println(c1()) // 3

c2 := counter() // новый, независимый счётчик со своей копией count
fmt.Println(c2()) // 1
```

Каждый вызов `counter()` создаёт новую переменную `count` в памяти — замыкания `c1` и `c2` держат ссылки на разные экземпляры этой переменной, не пересекаясь.

## 6. defer

`defer` откладывает выполнение функции до момента выхода из окружающей функции (return, panic, или конец тела функции) — независимо от того, каким путём этот выход произошёл.

```go
func readFile() {
    file, err := os.Open("data.txt")
    if err != nil {
        return
    }
    defer file.Close() // выполнится ПЕРЕД выходом из readFile, что бы ни случилось дальше

    // ... работа с файлом, возможны и return, и panic ...
}
```

**Правила, которые часто спрашивают на собеседовании:**

1. **Аргументы defer вычисляются сразу**, а не в момент отложенного выполнения:

```go
i := 0
defer fmt.Println("значение i при defer:", i) // напечатает 0, а не 5!
i = 5
```

2. **Несколько defer выполняются в порядке LIFO** (стек — последний вызванный defer выполнится первым):

```go
defer fmt.Println("1")
defer fmt.Println("2")
defer fmt.Println("3")
// Вывод при выходе из функции: 3, 2, 1
```

3. **defer может изменить именованное возвращаемое значение** — используется для "постобработки" результата, в том числе для перехвата паники (см. следующий пункт):

```go
func safeDivide(a, b int) (result int, err error) {
    defer func() {
        if r := recover(); r != nil {
            err = fmt.Errorf("восстановились после паники: %v", r)
        }
    }()
    result = a / b // паника при b == 0
    return
}
```

## 7. Анонимные функции и немедленный вызов (IIFE)

```go
func() {
    fmt.Println("выполнилась сразу")
}()

result := func(a, b int) int {
    return a + b
}(3, 4)
fmt.Println(result) // 7
```

# Функции Go

Функция — именованный блок кода, который выполняет отдельную задачу.

## Объявление функции

```go
func add(a int, b int) int {
	return a + b
}
```

Здесь:

* `add` — имя функции;
* `a` и `b` — параметры;
* `int` после `)` — тип возвращаемого значения;
* `return` — возвращает результат.

## Вызов функции

```go
result := add(5, 7)
```

После вызова:

```text
result = 12
```

Параметры указываются при объявлении функции:

```go
func add(a int, b int) int
```

А при вызове передаются только значения:

```go
add(5, 7)
```

## Несколько параметров одного типа

Можно сократить запись:

```go
func multiply(a, b int) int {
	return a * b
}
```

Это то же самое, что:

```go
func multiply(a int, b int) int {
	return a * b
}
```

## Функция с одним параметром

```go
func square(n int) int {
	return n * n
}
```

## `return`

`return` завершает выполнение функции.

```go
return
```

Просто завершает функцию.

```go
return value
```

завершает функцию и возвращает значение вызывающему коду.

Пример:

```go
func square(n int) int {
	return n * n
}
```

Вызов:

```go
result := square(5)
```

получит:

```text
result = 25
```

## Параметр и аргумент

```go
func add(a, b int) int {
	return a + b
}
```

`a` и `b` — параметры.

```go
add(5, 7)
```

`5` и `7` — аргументы.

## Основная схема

```text
main
 ↓
получить данные
 ↓
передать аргументы функции
 ↓
функция выполняет свою задачу
 ↓
return
 ↓
получить результат
```

Хорошая практика — функция должна выполнять одну понятную задачу, а `main` организовывать общий порядок работы программы.
